# تطبيق التحكم بالمودم D-Link DVG-M3521U

مشروع Android أولي بواجهة عربية للتحكم بالمودم من الهاتف.

## الحالة الحالية
هذه نسخة أولية تفتح صفحة إدارة المودم المحلية `http://192.168.1.1/` داخل التطبيق. لا تنفّذ تغييرات تلقائية على إعدادات المودم بعد؛ يجب فحص واجهة الويب وطلبات HTTP الفعلية أولًا قبل إضافة أزرار تحكم آمنة.

## البناء
يُبنى التطبيق تلقائيًا عبر GitHub Actions عند الدفع إلى الفرع `main`، ويمكن تشغيل سير العمل يدويًا من تبويب Actions.

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
